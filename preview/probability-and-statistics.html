第一章 随机事件和概率

1.1 随机事件

一、概率论的诞生及应用

1. 诞生：有人称之为"赌徒玩的游戏"。

2. 应用：天气预报、地震预报、密码学、股市、产品抽样调查等。

二、随机现象

1. 确定性现象：在一定条件下必然发生的现象。例如太阳东升西落、水从高处流向低处、三角形内角和为180°等。研究这类现象的数学工具是线性代数、微积分等经典数学理论。

2. 随机现象：在一定条件下可能出现，也可能不出现的现象。例如掷色子观察点数、从含正品和次品的产品中任取一件、明天的天气等。随机现象的发生既有偶然性，也有其必然性，是有规律可循的。概率统计就是研究随机现象规律性的一门学科。

3. 随机试验：满足以下条件的试验称为随机试验：

  • 可以在相同条件下重复进行；
  • 所有可能结果事先可明确知道；
  • 每次恰好出现可能结果中的一个，但不确定出现哪一个。

三、样本空间及事件

1. 样本空间：试验中每一种可能出现的最简单结果，称为基本事件或样本点，记为ω。所有样本点构成的集合称为样本空间，记为Ω，即 Ω = {ω₁, ω₂, …, ωₙ, …}。

例1 掷色子：Ω₁ = {1, 2, 3, 4, 5, 6}

例2 等车人数：Ω₂ = {0, 1, 2, …, n, …}

例3 灯管寿命：Ω₃ = {t | t ≥ 0} = [0, +∞)

例4 投点坐标：Ω₄ = {(x, y) | -∞ < x, y < +∞}

2. 事件：样本空间的子集称为随机事件，记为 A, B, C, …。事件 A 的某个样本点出现，称事件 A 发生。样本空间 Ω 又称为必然事件，∅ 称为不可能事件。

四、事件的关系及运算

1. 事件的关系：

定义1（包含）

若事件 A 发生，事件 B 必然发生，则称 B 包含 A，记为 A ⊂ B 或 B ⊃ A。

注：∅ ⊂ A ⊂ Ω；A ⊂ B 等价于"若 B 不发生，则 A 也不发生"。

定义2（相等）

若 A ⊂ B 且 B ⊂ A，则称 A 与 B 相等，记为 A = B。

定义3（和/并）

事件 A、B 中至少有一个发生，称为 A 与 B 的和（并），记为 A ∪ B。

注：A ⊂ A∪B，B ⊂ A∪B；A∪Ω = Ω，A∪∅ = A；若 A ⊂ B，则 A∪B = B。

定义4（交/积）

事件 A、B 同时发生，称为 A 与 B 的交（积），记为 A ∩ B 或 AB。

定义5（差）

事件 A 发生而 B 不发生，称为 A 与 B 的差，记为 A \ B。

定义6（对立/逆事件）

令 Ā = Ω \ A，则 Ā 即事件 A 不发生，称为 A 的对立事件。

注：AĀ = ∅，A ∪ Ā = Ω，Ā̄ = A；A \ B = A·B̄。

定义7（互不相容）

若 AB 是不可能事件，则称 A 与 B 互不相容（互斥）。

定义8（完备事件组）

若 A₁, A₂, …, Aₙ 两两互不相容，且 ⋃Aᵢ = Ω，则称它们构成一个完备事件组。

2. 事件的运算规律：

  • 交换律：A∪B = B∪A；AB = BA
  • 结合律：(A∪B)∪C = A∪(B∪C)；(AB)C = A(BC)
  • 分配律：A(B∪C) = AB∪AC；(AB)∪C = (A∪C)(B∪C)
  • De Morgan 律：A∪B 的对立 = Ā·B̄；AB 的对立 = Ā∪B̄；推广到 n 个事件同样成立。

1.2 随机事件的概率

一、概率的定义

1. 统计定义

频率：设事件 A 在 n 次重复试验中发生 m 次，称 fₙ(A) = m/n 为 A 的相对频率。

  • 非负性：0 ≤ fₙ(A) ≤ 1
  • 规范性：fₙ(Ω) = 1
  • 可加性：若 A、B 互斥，则 fₙ(A∪B) = fₙ(A) + fₙ(B)

概率的统计定义：刻画事件 A 发生可能性大小、介于 0 与 1 之间的数，记为 P(A)。P(A) 近似等于 fₙ(A)，是客观存在的。局限：需大量试验确定，不精确。

2. 古典定义

等可能性：由于对称条件，若干事件中每一事件发生的可能性完全相同。

设试验样本空间共有 N 个等可能基本事件，事件 A 含 M 个，

则 P(A) = M / N

★ 使用古典概型时，必须保证基本事件的等可能性！

3. 几何定义

在区域 G 内随机投点，落入子区域 g 的概率为：

P = m(g) / m(G) （m 为测度：长度、面积或体积）

4. 公理化定义

设 E 是随机试验，Ω 是样本空间，对每个事件 A 赋予实数 P(A)，若满足：

  • 非负性：0 ≤ P(A) ≤ 1
  • 规范性：P(Ω) = 1
  • 可列可加性：对两两互不相容事件 A₁, A₂, …，有 P(⋃Aᵢ) = ΣP(Aᵢ)

则称 P(A) 为事件 A 的概率。

二、概率加法法则

性质1

P(∅) = 0

性质2（有限可加性）

若 A₁, …, Aₙ 两两互不相容，则 P(ΣAᵢ) = ΣP(Aᵢ)。

性质3

对任意事件 A，P(Ā) = 1 − P(A)。

性质4（单调性）

若 A ⊃ B，则 P(A\B) = P(A) − P(B)，P(A) ≥ P(B)。

对任意 A, B：P(A\B) = P(A) − P(AB)。

性质5（加法公式）

P(A ∪ B) = P(A) + P(B) − P(AB)

推广到 n 个事件（容斥原理）：P(⋃Aᵢ) = ΣP(Aᵢ) − ΣP(AᵢAⱼ) + ΣP(AᵢAⱼAₖ) − … + (−1)ⁿ⁻¹P(A₁…Aₙ)

1.3 条件概率

一、条件概率与乘法公式

设 P(A) > 0，称 P(B|A) = P(AB) / P(A) 为在 A 发生条件下 B 发生的条件概率。

同理 P(A|B) = P(AB) / P(B) （P(B) > 0）

注：P(·|A) 是一个概率，满足非负性、规范性、可加性。

乘法公式

P(AB) = P(A)P(B|A) （P(A) > 0）

P(AB) = P(B)P(A|B) （P(B) > 0）

P(ABC) = P(A)P(B|A)P(C|AB) （P(AB) > 0）

一般：P(A₁A₂…Aₙ) = P(A₁)P(A₂|A₁)…P(Aₙ|A₁…Aₙ₋₁)

二、全概率公式和 Bayes 公式

全概率公式

设 A₁, A₂, …, Aₙ 为完备事件组，P(Aᵢ) > 0，则对任意事件 B：

P(B) = Σ P(Aᵢ)P(B|Aᵢ) (i = 1, 2, …, n)

Bayes 公式（逆概率公式）

P(Aₖ|B) = P(Aₖ)P(B|Aₖ) / Σ P(Aᵢ)P(B|Aᵢ)

注：P(Aᵢ) 称为先验概率（试验前已知）；P(Aᵢ|B) 称为后验概率（试验后 B 已发生时对原因的重新判断）。

★ 全概率公式用于"由因求果"，Bayes 公式用于"由果溯因"。

1.4 独立性

一、事件的独立性

定义：若 P(AB) = P(A)P(B)，则称 A 与 B 相互独立。

重要性质

1. 必然事件 Ω、不可能事件 ∅ 与任意事件独立。

2. 对非零事件 A, B：互不相容与相互独立不能同时成立。

3. 定理1：若 P(A) > 0，则 A, B 独立 ⇔ P(B|A) = P(B)。

4. 定理2：以下四个命题等价——(1)A与B独立；(2)A与B̄独立；(3)Ā与B独立；(4)Ā与B̄独立。

多个事件的独立性：对 A₁, …, Aₙ，若任意 k 个（2 ≤ k ≤ n）事件的积的概率等于各概率之积，则称它们相互独立。共需满足 2ⁿ − 1 − n 个等式。

独立事件的运算性质

1. 相互独立 ⇒ 其中任意 m 个也相互独立。

2. 独立事件中任意 m 个换成对立事件，仍相互独立。

3. P(A₁A₂…Aₙ) = P(A₁)P(A₂)…P(Aₙ)

4. P(A₁∪A₂∪…∪Aₙ) = 1 − P(Ā₁)P(Ā₂)…P(Āₙ)

二、Bernoulli 概型

n 重独立试验：完全相同条件下重复 n 次，各次结果互不影响。

n 重 Bernoulli 试验：每次试验只有 A 与 Ā 两个结果，P(A) = p，P(Ā) = 1−p = q。

定理：n 重 Bernoulli 试验中，A 恰好出现 k 次的概率为：

Pₙ(k) = C(n, k) · pᵏ · (1−p)ⁿ⁻ᵏ , k = 0, 1, …, n

第二章 随机变量及数字特征

2.1 随机变量

定义：若样本空间 Ω 中每个样本点 ω 都有唯一实数 X(ω) 与之对应，则 X(ω) 是定义在 Ω 上的实值函数，称为随机变量，简记为 r.v. X。常用 X, Y, Z 或 ξ, η 表示。

初等概率主要研究两种类型：离散型随机变量和连续型随机变量。

2.2 离散型随机变量及其分布列

一、离散型随机变量的分布率

若 X 的全部可能取值只有有限个或可数个，称 X 为离散型随机变量。

分布列：P(X = aₖ) = pₖ , k = 1, 2, …

或表格形式：X ~ (a₁, a₂, …; p₁, p₂, …)

性质：(1) pₖ ≥ 0（非负性）；(2) Σpₖ = 1（规范性）

二、几种常用离散型分布

1. 二项分布 B(n, p)

P(X = k) = C(n, k) · pᵏ · (1−p)ⁿ⁻ᵏ , k = 0, 1, …, n

记为 X ~ B(n, p)。当 n = 1 时为 0-1 分布（两点分布）。

2. 几何分布 G(p)

Bernoulli 试验中直到 A 首次发生所需试验次数 X：

P(X = k) = (1−p)ᵏ⁻¹ · p , k = 1, 2, …

记为 X ~ G(p)。

3. 泊松分布 P(λ)

P(X = k) = (λᵏ / k!) · e⁻λ , k = 0, 1, 2, … (λ > 0)

记为 X ~ P(λ)。常见于稠密性问题：网站访问量、急诊人数、电话呼叫次数等。

泊松定理

设 n 重 Bernoulli 试验中 npₙ → λ（λ > 0），则：

limₙ→∞ C(n, k) pₙᵏ (1−pₙ)ⁿ⁻ᵏ = (λᵏ / k!) e⁻λ

应用：X ~ B(n, p)，当 n 较大、p 较小（通常 n ≥ 10, p ≤ 0.1）时，X 近似服从 P(np)。

2.3 随机变量的分布函数及连续型随机变量

一、分布函数

定义：F(x) = P(X ≤ x) , x ∈ R

性质：(1) 单调不减；(2) F(−∞) = 0, F(+∞) = 1；(3) 右连续 F(x+) = F(x)。

反之，满足以上三性质的函数必为某随机变量的分布函数。

命题：P(X < x) = F(x−0)；P(X = x) = F(x) − F(x−0)

二、概率密度

若存在非负可积函数 p(x)，使 F(x) = ∫₋ₒₒˣ p(y) dy，则称 X 为连续型，p(x) 为概率密度。

性质：(1) p(x) ≥ 0；(2) ∫₋ₒₒ⁺⁺∞ p(x) dx = 1；(3) F'(x) = p(x)；

(4) P(a ≤ X ≤ b) = F(b) − F(a) = ∫ₐᵇ p(x) dx；(5) P(X = x) = 0

三、常见连续型分布

1. 均匀分布 U(a, b)

p(x) = 1/(b−a) , a < x < b；其余为 0

F(x) = 0 (x<a); (x−a)/(b−a) (a≤x<b); 1 (x≥b)

应用：四舍五入误差、等待时间等。

2. 指数分布 E(λ)

p(x) = λ·e⁻λˣ , x > 0；其余为 0 (λ > 0)

F(x) = 1 − e⁻λˣ , x > 0

重要性质——无记忆性：P(X > s+t | X > s) = P(X > t)

3. 正态分布 N(μ, σ²)

p(x) = (1/√(2π)σ) · e^[−(x−μ)²/(2σ²)] , −∞ < x < +∞

记为 X ~ N(μ, σ²)。特点：中间大、两头小、左右对称。

μ 为均值（位置参数），σ 为标准差（形状参数，σ 越小越陡峭）。

标准正态分布 N(0, 1)

密度 φ(x) = (1/√(2π)) e^(−x²/2)，分布函数 Φ(x)。

性质：φ(x) = φ(−x)；Φ(−x) = 1 − Φ(x)；P(|X| < a) = 2Φ(a) − 1。

一般正态标准化：若 X ~ N(μ, σ²)，则 (X−μ)/σ ~ N(0, 1)。

P(a ≤ X ≤ b) = Φ[(b−μ)/σ] − Φ[(a−μ)/σ]

3σ 准则

P(μ−σ < X < μ+σ) = 2Φ(1) − 1 ≈ 0.6826

P(μ−2σ < X < μ+2σ) = 2Φ(2) − 1 ≈ 0.9544

P(μ−3σ < X < μ+3σ) = 2Φ(3) − 1 ≈ 0.9973

2.4 随机变量函数的分布

一、离散型

将 X 的取值代入 g(x) 得 Y 的取值，相同取值的概率累加即可。

二、连续型（分布函数法）

一般步骤

(1) 由 X 的值域确定 Y = g(X) 的值域 Ωᵧ；

(2) 对 y ∈ Ωᵧ，Fᵧ(y) = P(Y ≤ y) = P(g(X) ≤ y) = P(X ∈ Gᵧ) = ∫_{Gᵧ} p(x) dx；

(3) pᵧ(y) = F'ᵧ(y)。

定理（单调变换）

若 y = f(x) 严格单调，反函数 x = f⁻¹(y) 有连续导数，则：

pᵧ(y) = pₓ[f⁻¹(y)] · |[f⁻¹(y)]'| , α < y < β；其余为 0。

重要结论：若 X ~ N(μ, σ²)，Y = kX + b (k ≠ 0)，则 Y ~ N(kμ + b, k²σ²)。特别地，(X−μ)/σ ~ N(0, 1)。

2.5 随机变量的数字特征

一、数学期望

离散型：EX = Σ aᵢ pᵢ （要求 Σ|aᵢ|pᵢ < ∞）

连续型：EX = ∫₋ₒₒ⁺⁺∞ x·p(x) dx （要求 ∫|x|p(x) dx < ∞）

常用分布的期望

B(n, p)：EX = np

G(p)：EX = 1/p

P(λ)：EX = λ

U(a, b)：EX = (a+b)/2

E(λ)：EX = 1/λ

N(μ, σ²)：EX = μ

二、随机变量函数的数学期望

离散型：E[f(X)] = Σ f(aᵢ) pᵢ

连续型：E[f(X)] = ∫₋ₒₒ⁺⁺∞ f(x)·p(x) dx

性质：Ec = c；E(cX) = c·EX；E(X+b) = EX+b；E(kX+b) = k·EX + b

三、方差

定义：DX = E(X − EX)² （标准差 σ(X) = √DX）

计算公式：DX = EX² − (EX)²

性质：Dc = 0；D(kX + b) = k²·DX；DX ≤ E(X − c)²

常用分布的方差

B(n, p)：DX = np(1−p)

G(p)：DX = (1−p)/p²

P(λ)：DX = λ

U(a, b)：DX = (b−a)²/12

E(λ)：DX = 1/λ²

N(μ, σ²)：DX = σ²

四、矩与切比雪夫不等式

k 阶原点矩：EXᵏ； k 阶中心矩：E(X − EX)ᵏ。一阶原点矩为期望，二阶中心矩为方差。

切比雪夫不等式

设 DX 存在，则对任意 ε > 0：

P(|X − EX| ≥ ε) ≤ DX / ε²

第三章 随机向量的分布及数字特征

3.1 随机向量的分布

一、随机向量及其分布函数

n 维随机向量：设 X₁, …, Xₙ 是同一样本空间上的 n 个随机变量，称 X = (X₁, …, Xₙ) 为 n 维随机向量。

联合分布函数：F(x₁, …, xₙ) = P(X₁ ≤ x₁, …, Xₙ ≤ xₙ)。二维时 F(x, y) = P(X ≤ x, Y ≤ y)。

二维分布函数的性质

(1) 单调性：分别对 x 或 y 单调不减；

(2) 规范性：0 ≤ F ≤ 1，F(−∞, y) = F(x, −∞) = 0，F(+∞, +∞) = 1；

(3) 右连续性：对每个变量右连续；

(4) 非负性：P(x₁ < X ≤ x₂, y₁ < Y ≤ y₂) = F(x₂,y₂) − F(x₁,y₂) − F(x₂,y₁) + F(x₁,y₁) ≥ 0

边缘分布函数

Fₓ(x) = F(x, +∞)，Fᵧ(y) = F(+∞, y)

二、二维离散型随机变量

联合分布列：pᵢⱼ = P(X = xᵢ, Y = yⱼ) , i, j = 1, 2, …

性质：pᵢⱼ ≥ 0；ΣΣ pᵢⱼ = 1

边缘分布列：pᵢ. = P(X = xᵢ) = Σⱼ pᵢⱼ；p.ⱼ = P(Y = yⱼ) = Σᵢ pᵢⱼ

★ 联合分布列可唯一确定边缘分布列，但反之不成立。

三、二维连续型随机变量

若存在非负函数 p(x, y)，使 F(x, y) = ∫₋ₒₒˣ∫₋ₒₒʸ p(u, v) dudv，则称 (X, Y) 为二维连续型，p(x, y) 为联合密度。

性质：p ≥ 0；∫∫p dxdy = 1；∂²F/∂x∂y = p；P((X,Y)∈G) = ∬_G p(x,y) dxdy

边缘密度：pₓ(x) = ∫₋ₒₒ⁺⁺∞ p(x, y) dy；pᵧ(y) = ∫₋ₒₒ⁺⁺∞ p(x, y) dx

四、两个常用多维分布

1. 多维均匀分布 U(D)

p(x₁,…,xₙ) = 1/S_D , (x₁,…,xₙ) ∈ D；其余为 0

（S_D 为区域 D 的度量）

2. 二元正态分布 N(μ₁, μ₂, σ₁², σ₂², ρ)

p(x, y) = 1/[2πσ₁σ₂√(1−ρ²)] · exp{ −1/[2(1−ρ²)] · [(x−μ₁)²/σ₁² − 2ρ(x−μ₁)(y−μ₂)/(σ₁σ₂) + (y−μ₂)²/σ₂²] }

边缘：X ~ N(μ₁, σ₁²)，Y ~ N(μ₂, σ₂²)

独立 ⇔ ρ = 0

3.2 随机变量的独立性

定义：若对任意 x, y，F(x, y) = Fₓ(x)Fᵧ(y)，则 X 与 Y 相互独立。

离散型充要条件：P(X = xᵢ, Y = yⱼ) = P(X = xᵢ)P(Y = yⱼ)

连续型充要条件：p(x, y) = pₓ(x)·pᵧ(y)（p 连续时）

若 X, Y 独立，则对任意连续函数 f, g，f(X) 与 g(Y) 也独立。

3.3 二维随机向量的条件分布

一、离散型条件分布

P(X = xᵢ | Y = yⱼ) = pᵢⱼ / p.ⱼ （p.ⱼ > 0）

P(Y = yⱼ | X = xᵢ) = pᵢⱼ / pᵢ. （pᵢ. > 0）

二、连续型条件分布

条件密度：pᵧ|ₓ(y|x) = p(x, y) / pₓ(x) （pₓ(x) > 0）

条件分布函数：Fᵧ|ₓ(y|x) = ∫₋ₒₒʸ [p(x, v)/pₓ(x)] dv

二元正态的条件分布

若 (X, Y) ~ N(μ₁, μ₂, σ₁², σ₂², ρ)，则：

Y | X = x ~ N( μ₂ + ρ·σ₂/σ₁·(x−μ₁), σ₂²(1−ρ²) )

X | Y = y ~ N( μ₁ + ρ·σ₁/σ₂·(y−μ₂), σ₁²(1−ρ²) )

3.4 随机向量函数的分布

一、离散型

列出 (X, Y) 所有取值及对应概率，计算 Z = g(X, Y) 的取值，相同值概率相加。

可加性（独立同分布时）

泊松：若 X ~ P(λ₁), Y ~ P(λ₂) 独立，则 X+Y ~ P(λ₁+λ₂)

二项：若 X ~ B(n, p), Y ~ B(m, p) 独立，则 X+Y ~ B(n+m, p)

正态：若 X ~ N(μ₁, σ₁²), Y ~ N(μ₂, σ₂²) 独立，则 X+Y ~ N(μ₁+μ₂, σ₁²+σ₂²)

二、连续型

1. 一般方法（分布函数法）

步骤

(1) 确定 Z = g(X, Y) 的值域 Ω_z；

(2) F_z(z) = P(Z ≤ z) = P(g(X, Y) ≤ z) = ∬_{G_z} p(x, y) dxdy；

(3) p_z(z) = F'_z(z)

2. 和的分布（卷积公式）

Z = X + Y：p_z(z) = ∫₋ₒₒ⁺⁺∞ p(x, z−x) dx

X, Y 独立时：p_z(z) = ∫₋ₒₒ⁺⁺∞ pₓ(x) pᵧ(z−x) dx = ∫₋ₒₒ⁺⁺∞ pₓ(z−y) pᵧ(y) dy

3. 极值分布

M = max(X₁,…,Xₙ), N = min(X₁,…,Xₙ)（Xᵢ 独立）

F_M(z) = Π Fᵢ(z)， F_N(z) = 1 − Π [1 − Fᵢ(z)]

独立同分布时：F_M(z) = [F(z)]ⁿ，F_N(z) = 1 − [1−F(z)]ⁿ

密度：p_M(z) = n[F(z)]ⁿ⁻¹ p(z)，p_N(z) = n[1−F(z)]ⁿ⁻¹ p(z)

4. 变量变换法

定理

设 { U = g₁(X, Y); V = g₂(X, Y) } 有唯一反函数 { x = x(u, v); y = y(u, v) }，雅可比 J = ∂(x,y)/∂(u,v) ≠ 0，则：

p(u, v) = p(x(u, v), y(u, v)) · |J|

5. 增补变量法（积与商）

积 Z = XY：p_z(u) = ∫₋ₒₒ⁺⁺∞ (1/|v|) pₓ(u/v) pᵧ(v) dv

商 Z = X/Y：p_z(u) = ∫₋ₒₒ⁺⁺∞ |v| pₓ(uv) pᵧ(v) dv

3.5 随机向量的数字特征

一、随机向量函数的数学期望

离散型：E[g(X, Y)] = ΣΣ g(xᵢ, yⱼ) pᵢⱼ

连续型：E[g(X, Y)] = ∫∫ g(x, y) p(x, y) dxdy

二、期望与方差的性质

数学期望的性质

E(X + Y) = EX + EY（推广到 n 个）

若 X, Y 独立，则 E(XY) = EX · EY（推广到 n 个独立变量）

方差的性质

若 X, Y 独立，则 D(X ± Y) = DX + DY（推广到 n 个独立变量）

一般：D(X ± Y) = DX + DY ± 2cov(X, Y)

三、协方差及相关系数

协方差：cov(X, Y) = E[(X−EX)(Y−EY)] = E(XY) − EX·EY

相关系数：ρ_XY = cov(X, Y) / (√DX · √DY) （DX·DY ≠ 0）

性质：|ρ_XY| ≤ 1

协方差性质

cov(X, X) = DX；cov(X, Y) = cov(Y, X)

cov(X, a) = 0；cov(aX, bY) = ab·cov(X, Y)

cov(X+Y, Z) = cov(X, Z) + cov(Y, Z)

D(X+Y+Z) = DX + DY + DZ + 2cov(X,Y) + 2cov(Y,Z) + 2cov(X,Z)

相关性

ρ = 0 称不相关；ρ > 0 正相关；ρ < 0 负相关；ρ = ±1 完全线性相关。

四个命题等价：(1) cov(X,Y) = 0；(2) E(XY) = EX·EY；(3) D(X+Y) = DX + DY；(4) X, Y 不相关。

独立 ⇒ 不相关；反之不成立（但二元正态下独立 ⇔ 不相关 ⇔ ρ = 0）。

ρ = ±1 ⇔ 存在 a ≠ 0, b 使 P(Y = aX + b) = 1。

第四章 极限定理

4.1 大数定律

背景：大量重复试验中，随机事件的发生呈现统计规律性（频率稳定性）。大数定律阐明大量随机变量平均值的稳定性。

定义：设 {Xₙ} 为随机变量列，若存在常数列 {aₙ}，对任意 ε > 0：

limₙ→∞ P( |(1/n)ΣXₖ − aₙ| < ε ) = 1

则称 {Xₙ} 服从大数定律。特别地 aₙ = (1/n)ΣEXₖ 时为经典大数定律。

定理1：切比雪夫大数定律

设 {Xₙ} 独立，EXᵢ 存在，且存在常数 c 使 DXₖ ≤ c，则 {Xₙ} 服从大数定律。

证明利用切比雪夫不等式：P(|(1/n)ΣXᵢ − (1/n)ΣEXᵢ| ≥ ε) ≤ (1/n²ε²)ΣDXᵢ ≤ nc/(n²ε²) → 0

定理2：贝努里大数定律

设 μₙ 为 n 重 Bernoulli 试验中 A 发生的次数，P(A) = p，则：

limₙ→∞ P( |μₙ/n − p| < ε ) = 1

意义：可以用频率作为概率的近似值；小概率事件原理（实际推断原理）。

定理3：辛钦大数定律

设 {Xₙ} 独立同分布，EX₁ = a，则对任意 ε > 0：

limₙ→∞ P( |(1/n)ΣXᵢ − a| < ε ) = 1

意义：用算术平均数作为期望的理论依据；矩估计方法的理论基础。

4.2 中心极限定理

背景：自然界中大量随机变量服从或近似服从正态分布。中心极限定理阐明独立随机变量之和在什么条件下以正态分布为极限。

规范和：Yₙ = (ΣXₖ − ΣEXₖ) / √(ΣDXₖ)

若 limₙ→∞ P(Yₙ ≤ x) = Φ(x)，则 {Xₙ} 满足中心极限定理。

定理1：Lindeberg-Levy 中心极限定理（独立同分布）

设 X₁, X₂, … 独立同分布，EX₁ = μ，DX₁ = σ² ≠ 0，则：

limₙ→∞ P( (ΣXₖ − nμ) / (√n · σ) ≤ x ) = Φ(x)

即当 n 充分大时，ΣXₖ 近似服从 N(nμ, nσ²)。

定理2：德莫佛-拉普拉斯定理（二项分布的正态近似）

设 μₙ ~ B(n, p)，则：

limₙ→∞ P( (μₙ − np) / √(npq) ≤ x ) = Φ(x)

二项分布近似：P(k₁ < X < k₂) ≈ Φ[(k₂−np)/√(npq)] − Φ[(k₁−np)/√(npq)]

用频率估算概率的误差

P( |μₙ/n − p| < ε ) ≈ 2Φ( ε·√(n/(pq)) ) − 1

★ 中心极限定理是数理统计中大样本统计推断的理论基础。

第五章 数理统计的基本概念

5.1 总体与样本

总体：被研究对象的全体。组成总体的每个单元叫个体。

样本：从总体中抽出若干个体而成的集体。样本中个体的数量叫样本容量。

简单随机样本

(1) 代表性：与总体有相同的分布；

(2) 独立性：X₁, X₂, …, Xₙ 相互独立。

（本书只研究简单随机样本）

统计量：不含未知参数的样本函数 f(X₁, …, Xₙ)。统计量的分布称为抽样分布。

★ 判断是否为统计量的关键：是否含有未知参数。

5.2 经验分布函数

将样本观测值排序：x₁* < x₂* < … < xₙ*，

Fₙ(x) = 0 (x < x₁*)；k/n (xₖ* ≤ x < xₖ₊₁*)；1 (x ≥ xₙ*)

性质：Fₙ(x) 是分布函数；由贝努里大数定律，Fₙ(x) → F(x)（依概率）。

5.3 样本分布的数字特征

常用统计量

样本均值：X̄ = (1/n) ΣXᵢ

样本方差：S² = (1/(n−1)) Σ(Xᵢ − X̄)² = (1/(n−1))(ΣXᵢ² − nX̄²)

样本 k 阶原点矩：Vₖ = (1/n) ΣXᵢᵏ

样本 k 阶中心矩：Uₖ = (1/n) Σ(Xᵢ − X̄)ᵏ

定理

定理1：E(X̄) = EX = μ，D(X̄) = DX/n = σ²/n

定理2：E(S²) = σ²（S² 是 σ² 的无偏估计）

5.4 常用分布及分位数

一、χ² 分布

设 X₁, …, Xₙ 独立同分布 N(0, 1)，则 χ² = X₁² + … + Xₙ² ~ χ²(n)

E(χ²) = n，D(χ²) = 2n

可加性：χ₁² ~ χ²(n₁), χ₂² ~ χ²(n₂) 独立 ⇒ χ₁² + χ₂² ~ χ²(n₁+n₂)

二、t 分布

设 X ~ N(0, 1), Y ~ χ²(n) 独立，则 T = X / √(Y/n) ~ t(n)

n = 1 时为 Cauchy 分布；密度关于 x = 0 对称；

n > 1 时 ET = 0；n > 2 时 DT = n/(n−2)；n → ∞ 时 t(n) → N(0, 1)

三、F 分布

设 X ~ χ²(n₁), Y ~ χ²(n₂) 独立，则 F = (X/n₁) / (Y/n₂) ~ F(n₁, n₂)

性质：F ~ F(n₁, n₂) ⇒ 1/F ~ F(n₂, n₁)；T ~ t(n) ⇒ T² ~ F(1, n)

四、分位数

上侧分位数：P(X > F_α) = α。

  • 标准正态：u₀.₅ = 0；u₁₋α = −uₐ
  • t 分布：t₀.₅(n) = 0；t₁₋α(n) = −tₐ(n)
  • F 分布：F₁₋α(n₁, n₂) = 1 / Fₐ(n₂, n₁)

5.5 常用抽样分布

定理4（正态样本线性函数）

设 Xᵢ ~ N(μᵢ, σᵢ²) 独立，则 η = ΣaᵢXᵢ ~ N(Σaᵢμᵢ, Σaᵢ²σᵢ²)

推论1

设 X₁, …, Xₙ ~ N(μ, σ²)，则 X̄ ~ N(μ, σ²/n)，(X̄ − μ)/(σ/√n) ~ N(0, 1)

定理5（单正态总体）

设 X₁, …, Xₙ ~ N(μ, σ²)，则：

(1) X̄ ~ N(μ, σ²/n)

(2) (n−1)S²/σ² ~ χ²(n−1)

(3) X̄ 与 S² 相互独立

推论2（t 分布）

T = √n (X̄ − μ) / S ~ t(n−1)

推论3（双正态总体方差比）

F = (Sₓ²/σ₁²) / (Sᵧ²/σ₂²) ~ F(m−1, n−1)

若 σ₁² = σ₂²，则 F = Sₓ²/Sᵧ² ~ F(m−1, n−1)

推论4（双正态总体均值差）

[X̄ − Ȳ − (μ₁ − μ₂)] / √[((m−1)Sₓ² + (n−1)Sᵧ²)/(m+n−2) · (1/m + 1/n)] ~ t(m+n−2)

第六章 参数估计

参数估计分类：点估计（用一个数值估计参数）和区间估计（用一个区间估计参数）。

6.1 点估计

一、矩估计

理论基础：辛钦大数定律——样本 k 阶矩依概率收敛到总体 k 阶矩。

替换原理（K. Pearson, 1900）

用样本矩替换总体矩，样本矩的函数替换总体矩的同一函数。

矩方程组：X̄ʲ = EXʲ , j = 1, 2, …, k

解方程组得 θ̂ⱼ = θⱼ(X₁, …, Xₙ)

例：N(μ, σ²) 的矩估计

EX = μ = X̄

EX² = μ² + σ² = (1/n)ΣXᵢ²

解得：μ̂ = X̄，σ̂² = (1/n)Σ(Xᵢ − X̄)² = ((n−1)/n) S²

二、极大似然估计 (MLE)

思想：选择使样本观测值出现可能性最大的参数值作为估计。

似然函数

离散型：L(θ) = Π P(Xᵢ = xᵢ)

连续型：L(θ) = Π p(xᵢ, θ)

L(θ) 反映了样本取到观测值的可能性大小。

极大似然估计步骤

(1) 写出似然函数 L(θ)；

(2) 取对数得对数似然函数 ln L(θ)；

(3) 对 θ 求导（多参数求偏导）并令为 0，得似然方程；

(4) 解方程得 θ̂，使 L(θ̂) = max L(θ)。

例：N(μ, σ²) 的 MLE

μ̂ = X̄，σ̂² = (1/n)Σ(Xᵢ − X̄)² = ((n−1)/n) S²

（正态总体下 MLE 与矩估计结果相同）

例：U(0, θ) 的 MLE

L(θ) = 1/θⁿ，ln L = −n ln θ，导数 −n/θ < 0，单调递减。

注意 0 ≤ xᵢ ≤ θ ⇒ θ ≥ max xᵢ，故最大值在边界 θ̂ = max(X₁, …, Xₙ)。

比矩估计 θ̂ = 2X̄ 更合理。

矩估计 vs 极大似然估计

矩估计：不需知总体分布类型，理论基础是大数定律，要求大样本，只能估计与矩有关的参数。

MLE：需知总体分布类型，可估计更复杂参数，性质更优良，但求解似然方程可能困难。

三、估计量的评价标准

1. 无偏性

若 E(θ̂) = θ，则称 θ̂ 为 θ 的无偏估计；否则为有偏估计。

X̄ 是 μ 的无偏估计；S² 是 σ² 的无偏估计。

2. 有效性

设 θ̂₁, θ̂₂ 都是 θ 的无偏估计，若 D(θ̂₁) ≤ D(θ̂₂)，则 θ̂₁ 比 θ̂₂ 有效。

在所有无偏估计中方差最小者称为有效估计。

3. 一致性（相合性）

若对任意 ε > 0，limₙ→∞ P(|θ̂ₙ − θ| ≥ ε) = 0，则 θ̂ₙ 为 θ 的相合估计。

X̄ 是 μ 的相合估计；S² 是 σ² 的相合估计。

相合性是对估计量的最基本要求。
